# Project instructions

Read `docs/PROJECT_RULES.md` before modifying this project. The user's current instructions take precedence.

- Use Next.js App Router and TypeScript; use Phosphor Icons exclusively.
- Do not use Sites skills for this project's design.
- Preserve original research workbooks. Keep research data separate from UI components.
- Retain source dates and distinguish ranking snapshots, benchmark publication years, estimates, missing values, and hypotheses.
- Reimport workbook data after source changes; use `npm run data:import`.
- Validate data changes against the XLSX source and interface changes in a real browser. Check 1920, 1440, tablet, mobile, filters, comparison, navigation, console and overflow.
- Run the relevant Playwright tests and production build before reporting completion.
