# PLAYFIELD v2

공동 개발팀을 위한 모바일 게임 시장 리서치 대시보드. Next.js App Router, TypeScript, React, Phosphor Icons를 사용합니다. 원본 XLSX를 읽어 게임, 순위 기록, 전략 분석, 원자료 시트를 분리합니다.

- 대시보드: [PLAYFIELD v2](https://jincoy.github.io/mobile-game-market-research/)
- 공개 저장소: [JinCoy/mobile-game-market-research](https://github.com/JinCoy/mobile-game-market-research)

현재 버전은 **v2.1.0**입니다. 원자료 6단계-3·6단계-4를 반영했고, 상단 메뉴를 `홈 · 시장조사 · 게임전략 · 업데이트 기록` 4개로 줄였습니다. 각 워크북의 시트는 왼쪽 목차(모바일은 접히는 목차)에서 엽니다. 목차는 엑셀의 ‘0 목차’에서 읽기 때문에 시트가 늘어나도 코드를 고치지 않습니다. 단계별 변경은 사이트의 **업데이트 기록**에 있습니다. v2.0 구현 내역은 [docs/IMPLEMENTATION_REPORT.md](docs/IMPLEMENTATION_REPORT.md)에 있습니다.

## 현재 자료

- 시장조사.xlsx 25개 + 게임전략_MVP_마케팅.xlsx 26개 = 51개 시트, 520개 순위 기록(확인 불가 13칸 포함), 7개국.
- 미국 무료 Top 100: App Store 2026-10-03, Google Play 2026-10-04.
- 미국 매출 Top 100: Google Play 2026-10-04, App Store 2026-10-06(88위까지 공개, 89~100위 확인 불가).
- 매출-다운로드 비교 172개 게임의 Google Play 공식 설치 구간·출시 월(2026-10-07 조회). 실제 다운로드 수는 아닙니다.
- 국가별 Google Play 무료 Top 20: 캐나다, 브라질, 멕시코, 일본, 한국, 인도네시아. 국가마다 조사일이 다릅니다.
- 2025 벤치마크 보고서는 순위 자료의 연도가 아닙니다. 각 벤치마크의 발행 연도, 관측 기간, 판독값 여부는 원자료에서 확인합니다.

## 실행과 검증

Node.js 20.9 이상이 필요합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run start
npm test
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. Playwright 설정에서 실행 채널을 변경할 수 있습니다. 테스트는 검색, 필터, 비교, 관심 게임 보존, CSV 다운로드, 출처 탐색, 모바일 가로 넘침, 콘솔 오류를 확인합니다.

## 데이터 갱신

원본 파일을 유지한 채 다음 명령으로 `data/market.json`을 다시 생성합니다. 원본 XLSX는 변경하지 않습니다.

```sh
npm run data:import
```

가져오기 스크립트는 Python + openpyxl이 설치된 로컬 가상 환경, 시스템 Python, Codex의 번들 Python 순서로 찾습니다. 다른 환경에서는 `requirements.txt`를 설치하거나 `PLAYFIELD_PYTHON`으로 Python 실행 파일을 지정합니다. 원본 파일은 Unicode NFC/NFD 파일명 모두 지원합니다.

`data/import-config.json`의 매출 조사일(Google Play `grossingDate`, App Store `appStoreGrossingDate`)과 설치 추정 기준일은 원자료를 갱신할 때 함께 수정합니다. 무료 순위 조사일은 개요 시트에서, 국가별 조사일은 각 기록에서 읽습니다. 수식은 다시 계산하지 않고 저장된 셀 값을 읽습니다. Excel에서 계산 후 저장한 파일을 사용해야 합니다.

`src/lib/schema.ts`는 공통 스키마입니다. `Game`은 게임 정보와 전략 분석, `Observation`은 국가·연도·날짜·스토어·순위 유형별 관측값을 정의합니다. 신규 관측값이 스키마에 맞게 추가되면 연도는 최신 조사 연도를 고정 표시하고, 날짜·국가 선택과 집계는 관측값에 맞게 확장됩니다. 현재 XLSX 어댑터는 제공된 시트 이름과 열 구조를 대상으로 합니다. 다른 시트 구조는 어댑터에서 매핑합니다. 재가져오기는 현재 워크북으로 데이터셋을 대체하며, 과거 스냅샷은 원자료에 남아 있는 행과 `snapshotFiles`에 등록한 추가 기록을 보존합니다. 같은 조건의 이전 기록을 원자료에서 지우지 않아야 합니다. 자세한 절차는 [데이터 수입 가이드](docs/DATA_IMPORT.md)에 있습니다.

`data/aliases.json`은 검토한 게임 이름 연결표입니다. 문장부호·대소문자 정규화 외에 불확실한 유사 이름은 자동으로 병합하지 않습니다. 동일 게임의 퍼블리셔 표기가 다른 경우 개별 순위 기록에 원래 표기가 남습니다.

`data/marketing-hypotheses.json`은 제공된 플레이 루프를 기반으로 작성한 광고 소재 테스트 가설입니다. 관측된 광고 성과와 구분해 표시합니다.

## 기능과 분석 기준

- Top 10 / 20 / 100 목록, 개별·전체 시장, 고정 조사 연도, 날짜, 스토어, 무료·매출 순위, 장르, 텍스트 검색.
- 장르별 스토어 비교, 게임별 상세 근거, 최대 6개 게임 비교, 관심 게임, 필터 범위 CSV.
- 게임플레이, BM, 마케팅, 아트, 지역 비교, MVP 자료 탐색.
- 시트 검색, 셀 행 번호, 개별 기록의 파일·시트·행·외부 링크.
- 누락 순위를 기록으로 유지합니다. Google Play 무료 80위와 App Store 매출 89~100위는 확인 불가입니다.
- 엑셀 칸 색을 그대로 옮깁니다: 노란 칸 = 추정·판독값·확인 필요, 초록 칸 = 확인됨, 파란 글씨 = 분석자 입력·가정값. 원자료 시트 화면에서 테두리·아이콘·글자로 구분합니다.
- 조사 게임 수는 누락을 제외하고 중복 게임을 제거합니다. 장르 막대 비율은 스토어의 수집된 순위 슬롯을 분모로 사용하고, 시장 신호의 비율은 확인된 게임 기록을 분모로 사용합니다.
- 무료·매출 순위는 수량이 아닙니다. AppBrain 추정 누적 설치는 국가별 실제 다운로드가 아닙니다. 캠페인 효과의 인과관계는 미확인입니다.

관심 게임은 각 브라우저에만 저장됩니다. 로그인, 팀별 접근 제어, 공동 편집, 자동 외부 수집은 구현되어 있지 않습니다. 사이트와 저장소는 공개 상태이며, 누구나 현재 조사 자료를 열람할 수 있습니다.

## GitHub 공유

`main`에 변경 사항을 올리면 GitHub Actions가 타입·빌드·브라우저 테스트를 확인한 뒤 GitHub Pages에 자동 배포합니다. Pull request에서는 검증만 실행합니다. 원본 XLSX, 생성된 JSON, 잠금 파일, 디자인 문서가 함께 포함되어 다른 개발자가 같은 프로젝트를 재현할 수 있습니다.

GitHub Pages에서는 정적 내보내기를 사용하며 저장소 이름에 맞는 경로를 빌드에 포함합니다. 로컬 개발 서버는 기존처럼 `/`에서 실행합니다. 공개 사이트도 `PLAYFIELD_TEST_URL`을 지정해 같은 브라우저 테스트를 실행할 수 있습니다.

프로젝트의 사용자 규칙은 [docs/PROJECT_RULES.md](docs/PROJECT_RULES.md)에 보존합니다.

## 디자인

[DESIGN.md](DESIGN.md)는 제공된 Binance 디자인 문서의 원문입니다. 기존 섹션 순서, 그리드, 반응형 배치와 인터랙션을 유지하고 `src/app/design-theme.css`에서 색상·타이포그래피·간격을 적용합니다. 원래 레이아웃과 전환 시간은 `src/app/globals.css`에 유지합니다.

문서의 대체 폰트 지침에 따라 본문은 Inter, 숫자는 IBM Plex Sans, 한국어는 Noto Sans KR을 사용합니다. 폰트는 Fontsource 패키지로 로컬 제공하며 외부 폰트 서버에 요청하지 않습니다. 데이터 상태 색(확인됨 초록, 분석자 입력·제안 보라, 노란 칸 점선)은 DESIGN.md 끝의 ‘Project tokens’에 HEX와 대비값으로 기록했습니다. 스토어 그래프는 노랑/회색으로 구분하고, 가격 등락 의미의 초록/빨강은 사용하지 않습니다.

순위표·게임 상세·6개 게임 비교에는 같은 Top 범위를 기준으로 순위를 시각화합니다. 공통 순위 축의 점과 숫자로 정확한 순위를 표시하며, 두 스토어 기록을 선으로 연결합니다. 순위는 다운로드·매출 수량이나 성과 점수가 아니며, 미수집·범위 밖·분석 미작성 상태를 구분합니다. 원자료의 수치와 분석 문장은 그대로 유지합니다.
