# PLAYFIELD

개발팀 내부용 모바일 게임 시장 리서치 대시보드. Next.js App Router, TypeScript, React, Phosphor Icons를 사용합니다. 원본 XLSX를 읽어 게임, 순위 기록, 전략 분석, 원자료 시트를 분리합니다.

## 현재 자료

- 시장조사.xlsx, 게임전략_MVP_마케팅.xlsx: 38개 시트, 420개 순위 기록, 7개국.
- 미국 무료 Top 100: App Store 2026-10-03, Google Play 2026-10-04.
- 미국 Google Play 매출 Top 100: 2026-10-04.
- 국가별 Google Play 무료 Top 20: 캐나다, 브라질, 멕시코, 일본, 한국, 인도네시아. 국가마다 조사일이 다릅니다.
- 2025 벤치마크 보고서는 순위 자료의 연도가 아닙니다. 각 벤치마크의 발행 연도, 관측 기간, 판독값 여부는 원자료에서 확인합니다.

## 실행과 검증

Node.js 20.9 이상이 필요합니다.

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run start
npm test
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. Playwright 설정에서 실행 채널을 변경할 수 있습니다. 테스트는 검색, 필터, 비교, 관심 게임 보존, CSV 다운로드, 출처 탐색, 모바일 가로 넘침, 콘솔 오류를 확인합니다.

## 데이터 갱신

원본 파일을 유지한 채 다음 명령으로 `data/market.json`을 다시 생성합니다. 원본 XLSX는 변경하지 않습니다.

```sh
npm run data:import
```

가져오기 스크립트는 Python + openpyxl이 설치된 로컬 가상 환경, 시스템 Python, Codex의 번들 Python 순서로 찾습니다. 다른 환경에서는 `requirements.txt`를 설치하거나 `PLAYFIELD_PYTHON`으로 Python 실행 파일을 지정합니다. 원본 파일은 Unicode NFC/NFD 파일명 모두 지원합니다.

`data/import-config.json`의 매출 조사일과 설치 추정 기준일은 원자료를 갱신할 때 함께 수정합니다. 무료 순위 조사일은 개요 시트에서, 국가별 조사일은 각 기록에서 읽습니다. 수식은 다시 계산하지 않고 저장된 셀 값을 읽습니다. Excel에서 계산 후 저장한 파일을 사용해야 합니다.

`src/lib/schema.ts`는 공통 스키마입니다. `Game`은 게임 정보와 전략 분석, `Observation`은 국가·연도·날짜·스토어·순위 유형별 관측값을 정의합니다. 신규 관측값이 스키마에 맞게 추가되면 연도, 날짜, 국가 선택과 집계가 자동으로 확장됩니다. 현재 XLSX 어댑터는 제공된 시트 이름과 열 구조를 대상으로 합니다. 다른 시트 구조는 어댑터에서 매핑합니다. 재가져오기는 현재 워크북으로 데이터셋을 대체하며, 과거 스냅샷은 자동 보관하지 않습니다. 과거 데이터 보관이 필요하면 별도 스냅샷 파일 또는 데이터베이스를 연결할 수 있습니다.

`data/aliases.json`은 검토한 게임 이름 연결표입니다. 문장부호·대소문자 정규화 외에 불확실한 유사 이름은 자동으로 병합하지 않습니다. 동일 게임의 퍼블리셔 표기가 다른 경우 개별 순위 기록에 원래 표기가 남습니다.

`data/marketing-hypotheses.json`은 제공된 플레이 루프를 기반으로 작성한 광고 소재 테스트 가설입니다. 관측된 광고 성과와 구분해 표시합니다.

## 기능과 분석 기준

- Top 10 / 20 / 100, 국가, 연도, 날짜, 스토어, 무료·매출 순위, 장르, 텍스트 검색.
- 장르별 스토어 비교, 게임별 상세 근거, 최대 3개 게임 비교, 관심 게임, 필터 범위 CSV.
- 게임플레이, BM, 마케팅, 아트, 지역 비교, MVP 자료 탐색.
- 시트 검색, 셀 행 번호, 개별 기록의 파일·시트·행·외부 링크.
- 누락 순위를 기록으로 유지합니다. Google Play 무료 80위는 미확인입니다.
- 조사 게임 수는 누락을 제외하고 중복 게임을 제거합니다. 장르 막대 비율은 스토어의 수집된 순위 슬롯을 분모로 사용하고, 시장 신호의 비율은 확인된 게임 기록을 분모로 사용합니다.
- 무료·매출 순위는 수량이 아닙니다. AppBrain 추정 누적 설치는 국가별 실제 다운로드가 아닙니다. 캠페인 효과의 인과관계는 미확인입니다.

현재 관심 게임은 브라우저에만 저장됩니다. 로그인, 팀별 접근 제어, 공동 편집, 자동 외부 수집은 구현되어 있지 않습니다. 내부 자료를 외부에 공개하기 전 접근 제어를 마련해야 합니다.

## GitHub 공유

로컬 Git 저장소와 CI를 준비했습니다. GitHub 원격 저장소는 아직 생성하거나 연결하지 않았습니다. 원격 연결 후 다른 개발자는 원본 파일과 생성된 JSON, 잠금 파일을 포함한 저장소를 받아 `npm ci`로 같은 환경을 실행할 수 있습니다. 내부 리서치 공유에는 비공개 저장소를 사용합니다.

프로젝트의 사용자 규칙은 [docs/PROJECT_RULES.md](docs/PROJECT_RULES.md)에 보존합니다.
