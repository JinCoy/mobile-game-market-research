작성일: 2026-10-05. 비교 기준: 현재 작업 폴더의 파일과 공개 사이트 배포 당시 Git 커밋 `ce85961f4ca0c5b5a1251f8d49de8fe8e44b40cf`.

`2-7 동남아 분석`은 비교 기준 커밋에도 있었다. 공개 사이트의 현재 데이터에도 인도네시아 무료 Top 20이 이미 들어 있다. 이번 교체에서 새로운 동남아 국가 순위가 추가된 것으로 처리하면 안 된다.

다만 웹에서는 이 시트의 순위 외 분석, 지역 특징, 벤치마크, 자료 공백을 구조화해 충분히 보여주지 않는다. 이 부분을 기존 `지역 비교` 안에서 확장한다. 태국·베트남·필리핀·말레이시아의 미확인 순위를 만들거나 아시아·아시아태평양 평균을 동남아 개별 국가의 관측값처럼 표시하지 않는다.

## 2. 데이터 수입에서 먼저 해결할 것

현재 `scripts/import_data.py`는 모든 시트를 `documents`에 읽지만, 주요 정규화 데이터에는 순위, 게임 전략 설명, 추정 설치만 넣는다. `npm run data:import`만 실행하면 새 시트는 자료·출처에 나타나지만 광고 비교 그래프와 실행안은 자동 생성되지 않는다.

1. 최초에 기준 커밋과 현재 XLSX를 다시 비교하고 변경 보고서를 확인한다. 사용자 원자료 변경을 되돌리지 않는다.
2. 기존 수입기를 유지하면서 새 시트별 데이터 추출을 추가한다. 원본을 쓰거나 재생성하지 않는다. 생성 코드 실행은 워크북을 덮어쓸 수 있으므로 웹 데이터 수입의 기본 절차로 사용하지 않는다.
3. 단순 수입 기준으로 시트 수는 43개에서 47개가 되어야 한다. 기존 수입 대상의 순위 관측 420건, 알려진 게임 243개와 누락 슬롯 1개는 이번 원자료 교체로 바뀌지 않는다. 새롭게 기존 원자료를 정규화하는 경우에는 증가 이유를 별도 설명한다.
4. 관측과 분석은 다른 컬렉션으로 보존한다. 광고 채널이나 실행 단계를 게임 순위 기록에 섞지 않는다.
5. 참조 시트는 원본을 가리키는 관계로 처리한다. 벤치마크·OS·순위를 원본과 참조본에서 중복 집계하지 않는다.
6. 원자료의 파일·시트·행·셀 범위·외부 URL과 조사일을 보존한다. 보고서 발행 연도, 관측 기간, 조회일, 데이터 가져온 시각을 구분한다.

필요한 최소 데이터 묶음은 `advertisingChannels`, `adHookSamples`, `adCreatives`, `marketingPlan`, `regionalBenchmarks`, `osDistribution`, `mvpAssessments`다. 실제 구현에서 별도 JSON 파일을 쓰거나 현재 Dataset을 확장하는 것은 유지보수성을 기준으로 선택한다. 모든 타입에 빈 필드를 일괄 추가하는 방식은 피한다.

공통 근거 필드는 자료가 뒷받침하는 범위에서 `observed`, `secondary`, `estimate`, `aiClassification`, `analystReading`, `proposal` 등을 구분한다. 원문도 보존하고 숫자형 신뢰도 점수는 새로 만들지 않는다.

### 수식과 빈칸 처리

추가된 4개 시트에서 수식 결과 캐시는 읽을 수 있었고, 전체 워크북의 저장된 Excel 오류 셀은 발견하지 않았다. 이는 Excel에서 모든 입력 변화의 재계산을 검증했다는 뜻은 아니다.

`2-4 2인 개발 MVP 판단`의 일부 수식 결과는 원래부터 조건에 따라 빈 문자열을 반환한다. 예: H39, H51은 평가 입력 부족 시 빈칸이다. 캐시가 비어 보인다는 이유만으로 재계산 실패 또는 0점으로 처리하지 않는다. 수식, 필수 입력, 저장된 결과를 함께 확인한다.

웹의 계산 기능은 지원할 계산식만 명시적으로 구현한다. 일반 Excel 수식 엔진을 새로 만들지 않는다. 예산·가중치 등 사용자가 바꾸는 가정은 로컬 화면 상태로 유지하고 XLSX를 수정하지 않는다.

## 3. 새 내용을 기존 섹션에 구현하는 방법

### 마케팅: 광고 채널 비교

- 원자료: `3-2 광고 채널 분석!A5:I12`, `A15:I23`, `A25:A31`.
- 공개 자료와 2인 팀의 분석자 평가를 분리해 표시한다.
- 5개 평가 축의 히트맵과 종합점수 가로 막대를 사용한다. 축은 모두 1~5, 종합점수는 0~100으로 단위를 명시한다.
- 기본 가중치는 B16:F16의 20%, 25%, 25%, 20%, 10%를 가져온다. 가중치 조정과 원자료 기본값 복원을 제공한다면 합계 검증 및 결과 갱신을 구현한다.
- 기준 점수는 Google Ads 94, Meta 인스타그램 66, Meta 페이스북 70, 틱톡 59, 인플루언서 51, Apple Ads 81, 광고 네트워크 72다. 이 값은 실제 광고 수익·설치 성과가 아니라 분석자 평가다.
- Meta의 인스타그램·페이스북을 독립된 공개 성과 순위로 표시하지 않는다. Google Ads 앱 캠페인을 유튜브만의 성과로 바꾸지 않는다.
- 채널별 게임 CPI는 미확인이다. 지역 CPI를 채널별 실제 CPI로 복제하지 않는다.

### 마케팅: 광고 후킹과 처음 3초

- 원자료: `3-3 후킹 영상 분석`.
- A11:G16의 후킹 유형과 A19:G26의 형식 빈도는 게임당 25개, 전체 75개 AI 분류 표본이다. 게임별 100% 누적 막대와 개수 직접 라벨을 사용한다.
- A30:H59는 광고 목록 30건이다. A63:F92는 별도의 처음 3초 분석자 판독 30건이다. 동일 광고 ID를 연결하되 표본 정의를 섞지 않는다.
- A63:F92의 실제 유형은 C열, 요청 유형으로 묶기는 D열, 설명은 E열, 같은 영상 묶음은 F열이다. H:L에는 옆에 배치된 별도 요약 표가 있어 행 단위 전체를 같은 레코드로 파싱하면 안 된다.
- 광고 레코드 기준 30건과 같은 영상 묶음을 중복 제거한 26개 영상을 구분한다. 기본 집계와 중복 제거 집계를 제공할 경우 분모를 동시에 표시한다.
- 광고 전체 현황, 추적 광고 수, AI 분류 완료 표본 수를 다른 지표로 표시한다. 집행 기간이나 소재 빈도를 효율·전환율로 해석하지 않는다.
- AdWhispr 추정 광고비는 추정 방법·기간 미확인 표시를 유지하고 게임 매출이나 실제 집행비로 합산하지 않는다.
- 미국 외 언어의 광고가 포함되어 있으므로 미국 전용 표본으로 이름 붙이지 않는다.
- 원문 확인 항목: MONOPOLY GO!의 브랜드 현황 F7은 203일이고 광고 목록 및 설명에는 204일이 등장한다. 같은 측정치로 강제 통일하지 말고 출처·범위 차이 또는 확인 필요로 보존한다.
- `3-2 광고 채널 분석!A31`의 다음 단계 안내 등 완료 상태와 맞지 않는 문구가 있으면 웹의 상태는 실제 시트 존재를 기준으로 결정한다. 원본 문구는 자료 화면에서 보존한다.
- 3개 게임의 기존 상세 비교에서 광고 근거를 연결한다. 다른 게임에 이 표본이나 전략을 자동 복제하지 않는다. 기존 `marketingHook` 가설과 새로 수집된 광고 판독은 서로 구분한다.

### 마케팅: 실행안과 예산 계산

- 원자료: `3-4 마케팅 실행안!A4:D4`, `A7:N13`, `A16:D21`, `A25:D31`, `A34:A38`.
- 준비, 브라질 1~4주, 인도네시아 5~8주, 미국 9~16주, 확대 17주 이후를 기존 마케팅 영역 안의 단계 도표로 표현한다. 예상 일정은 분석자 제안이라는 라벨을 유지한다.
- 예산, CPI, 예상 설치, D7 잔존을 단계별로 보여준다. 통화·인원·비율은 같은 축에 섞지 않는다. 설치와 D7 인원은 별도 공통 축의 작은 그래프로 비교한다.
- 기본 예산 합계는 $10,000, 계산된 설치 합계는 약 15,525명, D7 합계는 약 564명이다. 각각 다른 단계의 추정 결과 합계이며 실제 캠페인 성과 또는 동일 날짜 코호트가 아니다.
- 필요한 식만 구현한다: 예상 설치 = 예산 / CPI, 예상 D7 잔존 = 예상 설치 × 해당 지역 D7 P50. 계산에는 원래 소수값을 사용하고 표시할 때 반올림한다.
- 브라질에는 남미 CPI $0.14, 인도네시아에는 아시아태평양 CPI $0.27, 미국에는 미국 CPI $1.71을 사용한다. 지역 평균과 개별 국가의 실측값을 구분한다. 특히 아시아태평양 CPI와 아시아 리텐션의 지리 범위가 동일하다고 표현하지 않는다.
- 후보 선택을 바꿔도 근거 없는 후보별 CPI, 예산, 소재 계획을 자동 생성하지 않는다. 자료가 제공하는 후보 평가 요약과 실제로 연결된 계획만 갱신한다.
- 소재 A~E, 제작 난이도, 참고 게임과 표본을 연결한다. 계획의 합격 기준과 공개 벤치마크를 구분한다.

### 지역 비교: 동남아와 OS

- 국가별 순위는 실제 수집된 7개국 기준을 유지한다. 동남아 순위는 인도네시아 Top 20의 관측 범위로 표시한다.
- 기존 지역 비교 안에서 동남아 해설, 확인되지 않은 국가 범위, 원자료에 있는 지역 벤치마크를 연결한다. 무자료 국가에 빈 순위 표나 추정 순위를 채우지 않는다.
- `시장조사!2-6 대륙별 OS 분포`를 OS 그래프의 원본으로 사용한다. Android·iOS·기타의 100% 구성과 관측 월을 표시한다.
- StatCounter 표의 기준은 페이지뷰 기반 OS 사용 점유율이다. 기기 대수, 게임 이용자 비율 또는 게임 매출 비율로 바꾸지 않는다.
- OS 출시 우선순위는 점유율 원자료와 구분되는 분석자 제안으로 표시한다. 게임 시장의 매출·다운로드 OS 구성이 별도 표에 있다면 측정 대상과 기간을 별도로 보존한다.

### 개발 기회: MVP와 검증 기준

- 기존 `2-4 2인 개발 MVP 판단`, `2-1 MVP 명세`, `2-2 MVP 검증 목표`를 새 실행안에 연결한다. 이번 교체의 새 시트와 이전부터 있던 시트를 구분한다.
- 2인 개발 평가 점수는 분석자 평가로 표시하고 누락 평가를 0점으로 넣지 않는다. 후보 필터는 원자료의 판정 규칙을 보존한다.
- D1·D7·D30, ARPDAU 등은 지역·장르·백분위·출판 연도·관측 기간이 맞는 것끼리 공통 축의 작은 그래프 또는 기준점 그래프로 표현한다.
- 실제 게임 측정값이 없으면 참고 벤치마크만 보여준다. 목표 또는 계획을 실측으로 표시하지 않는다.

## 5. 구현 순서와 검증

1. 현재 변경 파일 보존, 비교 재확인, 스키마·수입기 확장, 원자료-정규화 값 대조.
2. 집계 범위·분모·누락·근거·분석 충실도 표시를 먼저 수정.
3. 순위·장르·6개 게임 비교·지역 차트 및 글씨 개선.
4. 광고 채널, 후킹, 예산 계산, 실행 계획, OS·동남아 해설, MVP·벤치마크를 해당 기존 섹션에 구현.
5. 소스 반환·필터·선택 게임 유지 등 기존 동작 검증.

필수 확인:

- 새 자료 시트 47개, 광고 채널 7개, AI 유형별 각 게임 25개·전체 75개, 영상 및 첫 3초 판독 각 게임 10개·전체 30개. 영상 중복 제거는 26개 기준으로 대조.

결과 보고에는 반영한 항목, 실제 최신 수치, 데이터 한계 때문에 구현하지 않은 추이 등, 브라우저 확인 결과와 대표 화면을 포함한다. 원자료의 미수집을 사용자에게 작업을 넘기는 이유로 삼지 말고 해당 기능을 이용 가능한 데이터 범위까지 구현한다.
