```text

먼저 AGENTS.md, docs/PROJECT_RULES.md, DESIGN.md, docs/WORKBOOK_UPDATE_GUIDE.md를 읽어라. 마지막 문서는 이전 창에서 현재 파일과 공개 배포 커밋 ce85961f4ca0c5b5a1251f8d49de8fe8e44b40cf를 비교해 작성한 변경 보고서 및 구현 가이드다. 현재 Git 상태와 원자료를 재확인해서 그 이후 변경도 반영해라.

현재 사용자가 교체한 파일:
- 게임전략_MVP_마케팅.xlsx
- 시장조사.xlsx
- 시장분석_스프레드시트_생성코드.py
마지막 파일은 엑셀이 아니라 워크북 생성 코드다. 한글 파일명의 NFC/NFD 차이를 처리해라. 사용자의 변경을 되돌리지 말고 원본 워크북을 수정하거나 생성 코드를 실행해서 덮어쓰지 마라.

지킬 조건:
- 기존 구조, 섹션 순서, 주요 레이아웃 배치를 유지한다. 새 정보는 기존 마케팅·지역 비교·개발 기회·자료 영역 안에 구현한다.
- 기존 애니메이션, 필터, 관심 게임, CSV, 상세 보기, 원자료에서 돌아가기 등 동작을 유지한다. 비교는 최대 6개다.
- 제목과 게임 이름을 임의로 바꾸지 않는다. 2026은 현재 자료가 한 연도이므로 선택 박스 대신 표시하는 동작을 유지한다.
- DESIGN.md의 어두운 바탕·노랑 강조·폰트 체계를 따른다. 색·글씨·간격으로 가독성을 개선하고, 정보 비교에 필요한 그래프와 로컬 조작 기능을 구현한다.
- Next.js App Router와 TypeScript를 유지하고 Phosphor Icons만 사용한다. Sites 스킬은 사용하지 않는다.
- 스프레드시트 분석에는 spreadsheets 스킬을 활용한다. 그래프는 공통 축, 직접 라벨, 단위·분모, 색상 외 구분, 누락값 구분을 적용한다. visualize는 대화 속 설명/비교가 필요할 때 활용하고 사이트용 코드는 실제 프로젝트에 구현한다.
- 관측, 추정, AI 분류, 분석자 판독, 가설, 제안, 벤치마크를 구분하고 파일·시트·행·날짜·원문을 보존한다.
- 반복 조사 자료가 없는 추이, 실제 광고 효율, 국가별 미수집 순위, 게임별 실제 매출을 만들어내지 않는다. 원자료의 평가 점수를 실제 성과로 바꾸지 않는다.

원자료 반영:
1. 새 시트 3-2 광고 채널 분석, 3-3 후킹 영상 분석, 3-4 마케팅 실행안, 4-7 대륙별 OS 분포(참조)를 정규화하여 웹의 주요 화면에서 읽고 비교할 수 있게 해라. 원자료 표만 보여주는 것으로 완료하지 마라.
2. 기존 수입기를 확장하고 npm run data:import를 수행해라. 참조본을 중복 집계하지 마라. 일반 Excel 수식 엔진은 만들지 말고 필요한 계산만 구현한다.
3. 광고 채널은 7개, AI 분류 표본은 게임당 25개, 첫 3초 판독은 게임당 10개다. 두 표본을 섞지 마라. 영상 목록 30건과 동일 영상 중복을 제거한 26개도 구분한다. 파싱 범위는 가이드를 따른다.
4. 광고 평가 가중치, 단계별 예산·CPI·예상 설치·D7, 소재 5종, 검증 지표를 원자료에 연결한다. 웹에서 가정을 조정할 수 있게 할 경우 원자료 기본값 복원과 계산 검증을 포함한다.
5. 동남아 시트와 인도네시아 순위는 이전 공개 버전에도 있었다. 최신 파일에 추가 국가가 실제로 있는지 확인하고, 없다면 기존 동남아 해설·벤치마크·OS 근거를 기존 지역 비교에서 더 잘 보여줘. 아시아 평균을 동남아 국가 실측값으로 표시하지 마라.
6. 자료 시트 수는 이번 비교 기준 43→47개다. 기존 순위 데이터에는 실질적인 변경이 없고 기존 수식 캐시의 작은 정밀도 차이는 새 성과가 아니다. 현재 파일을 재확인해서 최신 수치를 사용해라.

6) 국가별 2·3위 장르까지 읽히는 지역 차트와 일관된 장르 표현.

8) 6개 게임 비교의 숫자 그래프, 설명 요약·펼침, 고정 헤더/항목 열, 선택 게임별 해제.
9) 작은 보조 글씨·터치 영역 개선, 핵심값 중심의 노랑 강조.
10) 범위 밖·미수집·분석 미작성·해당 없음·의도적 빈 수식 결과 구분.
11) 원자료의 해당 행으로 이동·강조하고 돌아올 때 이전 화면 상태 복원. 근거·날짜 표시.
12) 국가×스토어별 수집 범위와 조사일 요약.
13) 게임별 국가 진입 수와 국가별 순위 비교.
14) 퍼블리셔별 중복 제외 게임 수와 순위 기록 수 비교.
15) 확인 가능한 BM·핵심 루프 태그, 분석 표본·미분류 수 표시.
16) 근거가 있는 지역·장르·백분위별 벤치마크 그래프와 향후 반복 관측 수입 방식. 현재 자료로 만들 수 없는 성장 추이는 구현 완료 항목과 구분해 보고.

수입기·집계 정확성부터 해결하고 차트·비교·새 광고/지역/MVP 정보를 구현해라. 사소한 구현 선택은 직접 판단해라. 원자료가 부족하면 해당 부분의 미수집 상태와 확인된 정보까지 완성하고 다른 작업을 계속해라.
```
